# ЕМИАС — Минздрав (CustomCogs)

Порт системы **ЕМИАС** в кастом-коги бота «Управление Департаментами» (ER:LC Россия).

## Возможности

- **Чистая БД** — никаких фейков. Старт с пустыми таблицами, данные только реальные (создаются игроками/врачами). Команда `/очистка` для удаления тестовых данных.
- **Роли**: Главврач, Врач, Регистратор, Медсестра. RBAC как в оригинале.
- **Пациенты**: `/карта`, `/привязать` (код с сайта), `/блок`/`/разблок` (главврач)
- **Запись**: `/записаться`, `/талон` (отмена), `/очередь` (сотрудникам), `/врачи`
- **Персонал**: `/добавить-сотрудника` (главврач, с выбором роли/специальности), `/персонал список|изменить|уволить`
- **Медицина**: `/прием` (ЭМК с МКБ-10), `/рецепт`, `/статистика` (главврач)
- **Визуал**: брендированные embeds (синий `#0063B0`, иконка ЕМИАС, footer-дисклеймер, статусные эмодзи, аккуратные поля)

## Структура

```
Minzdrav/
├── cogs/           # 17 слэш-команд
├── dataUtils/      # db.js (SQLite + миграции) + emias.js (домен-логика)
├── utils/          # constants.js, embeds.js, permissions.js
├── tasks/          # statusTask.js (ротация) + reminders.js (напоминания)
├── locales/        # ru.json / en.json
├── config.js       # цвета/иконка/дисклеймер
├── schema.txt      # Prisma дополнения (если используете общую БД)
└── data/emias.db   # создаётся автоматически
```

## Установка

1. Скопируйте папку `Minzdrav` в ваш форк `Department-Oversight-CustomCogs`.
2. Если используете Prisma — добавьте содержимое `schema.txt` в основной `schema.prisma` и `npx prisma migrate dev`.
3. Если без Prisma — ничего делать не нужно, коги используют `data/emias.db` (SQLite, WAL).

## Первый запуск

- Первый сотрудник: администратор Discord сервера выполняет `/добавить-сотрудника` (когда в БД ещё нет Главврача — разрешено админу).
- Далее Главврач добавляет остальных: `/добавить-сотрудника пользователь:@Ivan фио:"Иванов Иван Иванович" роль:Врач специальность:terapevt`

## Команды

| Команда | Описание | Доступ |
|---|---|---|
| `/помощь` | Список команд | Все |
| `/я`, `/персонажи` | Профиль | Все |
| `/привязать код:` | Привязать персонажа | Все |
| `/врачи` | Список врачей | Все |
| `/записаться врач: дата: время: персонаж:` | Запись | Граждане с персонажем |
| `/талон` / `/талон отменить:` | Талоны | Владелец / сотрудник |
| `/очередь дата:` | Очередь | Сотрудник |
| `/карта персонаж:` | Медкарта | Сотрудник (медданные только врачам) |
| `/статус состояние:` | Сменить статус | Сотрудник |
| `/добавить-сотрудника` | Добавить в штат | Главврач (первый — админ) |
| `/персонал список|изменить|уволить` | Управление штатом | Главврач |
| `/блок`, `/разблок` | Блок персонажа | Главврач |
| `/прием` | Запись ЭМК | Врач/Главврач |
| `/рецепт` | Рецепт | Врач/Главврач |
| `/статистика` | Статы | Главврач |
| `/очистка что:` | Удалить фейки | Главврач/Админ |

## Визуал

Все embeds:
- `setAuthor({ name: 'ЕМИАС — Минздрав', iconURL })` + `setColor(0x0063B0)` + `setThumbnail(ICON_URL)` + footer с дисклеймером.
- Статусы с эмодзи 🟡/🔵/🟢/🔴, доктора 🟢/🟡/⚫.
- Поля с обратными кавычками для номеров карт/талонов, жирный для ФИО.
